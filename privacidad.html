Política de privacidad

hidden-publicador · Última actualización: 17 de noviembre de 2026

Qué es

hidden-publicador es una herramienta privada de uso personal del creador de contenido hidden. Sirve para publicar sus propios videos (Reels, Shorts y videos de TikTok/YouTube) en sus propias cuentas de Instagram, Facebook, YouTube y TikTok, y para leer las estadísticas de esas publicaciones. No es un servicio abierto al público y no permite que otras personas conecten sus cuentas.

Qué datos usa

  • Datos básicos de las cuentas del propio creador (nombre de usuario, identificadores de la cuenta).
  • Los videos, títulos y descripciones que el creador publica.
  • Estadísticas de sus publicaciones (vistas, me gusta, comentarios, alcance) para mejorar su contenido.

No se recopilan datos de otros usuarios, seguidores ni espectadores más allá de las cifras agregadas que entregan las plataformas.

Cómo se guardan

Los permisos (tokens) y el historial de publicaciones se guardan solo en la computadora del creador. No se venden, no se comparten con terceros y no se usan para publicidad.

Servicios de terceros

La herramienta usa las API oficiales de Meta (Instagram y Facebook), Google (YouTube Data API y YouTube Analytics API) y TikTok (Login Kit y Content Posting API), conforme a sus condiciones. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. Ver también la Política de privacidad de Google.

Cómo revocar el acceso

El creador puede revocar el acceso en cualquier momento desde la configuración de seguridad de cada plataforma (Google: myaccount.google.com/permissions; Meta: configuración de integraciones comerciales; TikTok: apps conectadas). Al revocar, se eliminan los tokens guardados.

YouTube API Services

hidden-publicador usa los YouTube API Services (YouTube Data API v3 y YouTube Analytics API) para subir videos al canal del propio creador y leer las estadísticas de sus videos. Al usar estas funciones aplican los Términos de servicio de YouTube y la Política de privacidad de Google.

Borrado de datos

La herramienta guarda solo en la computadora del creador: el token de autorización y un historial de publicaciones (id y link de cada video). Se borran eliminando esos archivos o revocando el acceso en la página de permisos de seguridad de Google; al revocar, el token deja de funcionar y se elimina. Para pedir el borrado de cualquier dato, escribe a hiddenbush3@gmail.com: se atiende en un plazo máximo de 7 días.

Privacy Policy

hidden-publicador · Last updated: November 17, 2026

What it is

hidden-publicador is a private, personal-use tool of the content creator hidden. It publishes his own videos (Reels, Shorts and TikTok/YouTube videos) to his own accounts on Instagram, Facebook, YouTube and TikTok, and reads the statistics of those posts. It is not a public service and other people cannot connect their accounts.

Data used

  • Basic data of the creator's own accounts (username, account IDs).
  • The videos, titles and descriptions the creator publishes.
  • Statistics of his posts (views, likes, comments, reach) to improve his content.

No data from other users, followers or viewers is collected beyond the aggregated figures provided by the platforms.

Storage

Access tokens and the posting history are stored only on the creator's computer. They are not sold, not shared with third parties and not used for advertising.

Third-party services

The tool uses the official APIs of Meta (Instagram and Facebook), Google (YouTube Data API and YouTube Analytics API) and TikTok (Login Kit and Content Posting API), under their terms. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time from each platform's security settings (Google: myaccount.google.com/permissions; Meta: business integrations settings; TikTok: connected apps). Stored tokens are deleted when access is revoked.

YouTube API Services

hidden-publicador uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API) to upload videos to the creator's own channel and read statistics of his own videos. By using these features you agree to the YouTube Terms of Service, and the Google Privacy Policy applies.

Data deletion

The tool stores, only on the creator's computer, the authorization token and a posting history (id and link of each video). They are deleted by removing those files or by revoking access at Google's security permissions page; once revoked, the token stops working and is deleted. To request deletion of any data, email hiddenbush3@gmail.com: requests are handled within 7 days.
